Tailapps v0.2.0 updates the Go toolchain and dependencies and ships the merged runtime and input-contract improvements since v0.1.4.

- Build with Go 1.27.3 and refreshed x/net, x/sys, x/sync, and x/text dependencies. CI and release signing now scan the exact public dependency graph used by the binaries.
- Adopt the verified public jsonataddl v0.2.0 core and declared input contracts, improve pending-inbox reads for large backlogs, and strengthen JSON storage and URL authority checks.

**Upgrade impact:** the runtime identity changes. Existing projections remain queryable but ingestion stays upgrade-pending until an explicitly acknowledged reset. Review or export existing data before resetting. A binary upgrade preserves projections and does not activate definitions, reset data, or replay historical input.

See the [resident upgrade guide](https://github.com/generalbusiness-ai/tailapps/blob/v0.2.0/docs/reference/resident-upgrade.md). Signed macOS and Linux archives, pinned install/upgrade scripts, checksums, and build-provenance attestations are attached to this release.
